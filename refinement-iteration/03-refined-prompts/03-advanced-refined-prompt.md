# Meiosis – Advanced Refined Prompt

## Experiment Condition

**Lesson:** Meiosis  
**Learner Level:** Advanced  
**Iteration:** Pedagogical Profile Refinement

---

## Learning Objectives

The generated educational package must enable the learner to:

1. Identify the location of meiosis in reproductive/sexual cells in the male and female sex organs of plants and animals.
2. Define meiosis as nuclear division in a parent reproductive cell that produces four daughter cells called gametes.
3. Demonstrate chromosome-number reduction during meiosis, where each gamete contains half the chromosome number of the original cell, using the human example of 46 → 23 chromosomes.
4. Outline the quantitative result of meiosis: one parent reproductive cell produces four gametes, each containing half the original chromosome number.
5. Explain the biological significance of meiosis in contributing to the stability of chromosome number across generations.

---

## Fixed Retrieved Curriculum Knowledge

Use only the following curriculum knowledge.

### Learning Objective 1 – Location of Meiosis

- Meiosis occurs in reproductive/sexual cells responsible for producing gametes.
- These cells are located in the male and female sex organs of most animals and plants.

### Learning Objective 2 – Definition and Result

- Meiosis is a nuclear division of a parent reproductive cell.
- It produces four daughter cells called gametes.

### Learning Objective 3 – Chromosome-Number Reduction

- Each gamete contains half the chromosome number of the original parent cell.
- In humans, the parent cell has 46 chromosomes.
- The resulting gametes have 23 chromosomes each.

### Learning Objective 4 – Quantitative Progression

- One parent reproductive cell produces exactly four gametes.
- The curriculum representation shows:
  - one cell with 46 chromosomes;
  - then two cells with 23 chromosomes each;
  - then four gametes with 23 chromosomes each.

### Learning Objective 5 – Biological Significance

- Meiosis contributes directly to maintaining the stability of chromosome number in the species across generations.
