# Advanced Level Generation Prompt

## Experiment

Experiment 1 – Mitosis

## Learner Level

Advanced

## Original Prompt

Now generate the self-learning package for a learner classified as Advanced, using exactly the same experimental setup used for the Basic and Intermediate packages.

Keep all fixed elements unchanged:

- The same Grade 8 Palestinian Science curriculum source.
- The same selected Mitosis scope.
- The same five Learning Objectives.
- The same previously retrieved curriculum knowledge.
- The same four output components.

Change only the Pedagogical Profile to the previously defined Advanced Profile:

- Use the full scientific terminology available in the fixed curriculum knowledge accurately and directly.
- Provide deeper conceptual explanations by integrating relationships among the stages, processes, and structures already contained in the retrieved curriculum knowledge.
- Use clear but more academically developed language appropriate for an advanced Grade 8 learner.
- Provide low scaffolding and encourage greater learner independence.
- Integrate multiple related concepts rather than presenting them separately step by step.
- Target mainly Bloom’s Apply and Analyze levels.
- Exercises and self-assessment questions should require explanation, comparison, interpretation, prediction, justification, and drawing conclusions only where these can be supported by the fixed retrieved curriculum knowledge.

Important: Advanced does not mean adding higher-grade or external scientific content. Increase the depth of reasoning and cognitive demand using the same fixed curriculum knowledge. Do not introduce additional biological mechanisms, terminology, or facts simply to make the package more advanced.

Generate exactly these four components:

1. Explanations
2. Key Vocabulary
3. Exercises
4. Self-Assessment Questions

Do not add any additional sections.

Generate the package in Arabic for an advanced Palestinian Grade 8 learner.

Label the output:

Advanced Level – Mitosis

Do not discuss or compare it with the Basic or Intermediate packages in the generated output. Generate only the Advanced package.
