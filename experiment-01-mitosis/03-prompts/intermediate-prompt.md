# Intermediate Level Generation Prompt

## Experiment

Experiment 1 – Mitosis

## Learner Level

Intermediate

## Original Prompt

Now generate the self-learning package for a learner classified as Intermediate, using exactly the same experimental setup used for the Basic package.

Keep all fixed elements unchanged:

- The same Grade 8 Palestinian Science curriculum source.
- The same selected Mitosis scope.
- The same five Learning Objectives.
- The same previously retrieved curriculum knowledge.
- The same four output components.

Change only the Pedagogical Profile from Basic to the previously defined Intermediate Profile:

- Use standard scientific terminology from the curriculum, explaining terms when needed.
- Provide a moderate level of explanation with clear relationships between concepts and stages.
- Use moderately complex but Grade-8-appropriate sentences.
- Provide moderate scaffolding rather than step-by-step support throughout.
- Connect several related concepts together.
- Encourage the learner to make simple connections and apply what they have learned.
- Target mainly Bloom’s Understand and Apply levels.
- Exercises and self-assessment should require understanding and simple application, such as sequencing, explaining relationships, comparison, and applying knowledge to simple situations.

Generate exactly these four components:

1. Explanations
2. Key Vocabulary
3. Exercises
4. Self-Assessment Questions

Do not add any additional sections.

Do not introduce external scientific knowledge.

Generate the package in Arabic for a Palestinian Grade 8 learner.

Label the output:

Intermediate Level – Mitosis

Do not refer to or explain the Basic level in the generated package. Generate only the Intermediate package.
