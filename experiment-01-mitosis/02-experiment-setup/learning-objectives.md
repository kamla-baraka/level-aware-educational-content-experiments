# Learning Objectives

## Experiment
Experiment 1 – Mitosis

## Selected Lesson
Mitosis (الانقسام المتساوي)

## Fixed Learning Objectives

The following five learning objectives were defined before level-aware content generation and were kept fixed across the Basic, Intermediate, and Advanced levels.

By the end of the lesson, the learner should be able to:

1. Explain the purpose of mitosis.
2. Identify the main stages of mitosis in the correct sequence.
3. Describe the main changes that occur during each stage of mitosis.
4. Explain the final result of mitosis in terms of the number of daughter cells and chromosome number.
5. Relate relevant cellular structures, such as chromosomes and spindle fibers, to the process of mitosis.

## Experimental Control

The learning objectives were held constant across all three learner levels:

- Basic
- Intermediate
- Advanced

The learner level did not change what the learner was expected to learn. Instead, the pedagogical profile changed how the same curriculum-grounded knowledge and learning objectives were presented and assessed.

This control was used to support comparison of level-aware generation while maintaining the same instructional scope across the three generated educational packages.
