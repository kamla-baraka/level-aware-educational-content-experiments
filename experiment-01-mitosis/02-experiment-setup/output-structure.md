# Fixed Output Structure

## Experiment
Experiment 1 – Mitosis

## Purpose

A fixed output structure was used across the Basic, Intermediate, and Advanced generation conditions to support a controlled comparison between learner levels.

Each generated educational package was required to contain the same four components.

## Output Components

1. **Explanations**
   - Presentation of the lesson content according to the assigned pedagogical profile.

2. **Key Vocabulary**
   - Key curriculum terms relevant to the selected Mitosis lesson.

3. **Exercises**
   - Practice activities designed according to the cognitive demand of the assigned learner level.

4. **Self-Assessment Questions**
   - Questions allowing the learner to check understanding of the lesson content at the assigned level.

## Experimental Control

The four output components were kept fixed across all three learner levels:

- Basic
- Intermediate
- Advanced

The structure of the educational package therefore remained constant, while the pedagogical profile controlled differences in vocabulary, explanation depth, scaffolding, cognitive demand, learner independence, and assessment difficulty.

No additional output component was intentionally introduced for any learner level.
