# Pedagogical Profiles

## Experiment
Experiment 1 – Mitosis

## Purpose

Three pedagogical profiles were defined to control how the same curriculum-grounded knowledge was presented at different learner levels.

The curriculum source, lesson scope, learning objectives, retrieved knowledge, and output structure were kept fixed. The pedagogical profile was the main variable intentionally changed across the three generation conditions.

## Basic Level

| Parameter | Setting |
|---|---|
| Vocabulary | Simple and familiar vocabulary; essential scientific terms explained |
| Explanation Style | Short and clear sentences |
| Scaffolding | High |
| Concept Load | Limited |
| Examples | Simple examples |
| Cognitive Demand | Remember and Understand |
| Learner Independence | Low |
| Assessment Focus | Recall and simple understanding |

## Intermediate Level

| Parameter | Setting |
|---|---|
| Vocabulary | Curriculum terminology |
| Explanation Style | Moderate detail with relationships between concepts |
| Scaffolding | Moderate |
| Concept Load | Several related concepts |
| Examples | Application-oriented examples |
| Cognitive Demand | Understand and Apply |
| Learner Independence | Moderate |
| Assessment Focus | Sequencing, relationships, comparison, and simple application |

## Advanced Level

| Parameter | Setting |
|---|---|
| Vocabulary | Full curriculum terminology |
| Explanation Style | Deeper relationships and academically developed explanations appropriate for Grade 8 |
| Scaffolding | Low |
| Concept Load | Integrated concepts |
| Examples | Reasoning-oriented use of the same curriculum knowledge |
| Cognitive Demand | Apply and Analyze |
| Learner Independence | High |
| Assessment Focus | Explain, predict, justify, and conclude within the fixed curriculum scope |

## Grounding Constraint

The Advanced profile was intended to increase cognitive demand and depth of reasoning without introducing outside or higher-grade scientific content.

All three levels were required to remain within the same fixed curriculum knowledge boundary.
