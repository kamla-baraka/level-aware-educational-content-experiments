# Advanced Level Generation Prompt

## Experiment

Experiment 2 – Meiosis

## Learner Level

Advanced

## Original Prompt

Generate the Advanced-Level Educational Package for the fixed Meiosis lesson.

Keep exactly the same:

Curriculum Source  
Meiosis Scope  
Five Learning Objectives  
Fixed Retrieved Curriculum Knowledge  
Four-Component Output Structure

Change only the Pedagogical Profile to the fixed Advanced Profile:

Use full curriculum scientific terminology.  
Provide deeper conceptual relationships while remaining strictly within the same fixed Grade 8 curriculum knowledge.  
Use academically developed but Grade-8-appropriate explanations.  
Provide low scaffolding.  
Integrate the fixed concepts rather than presenting them only as isolated facts.  
Target mainly Apply and Analyze.  
Assume high learner independence.  
Exercises and self-assessment should require analysis, comparison, interpretation, justification, and conclusion only where these can be performed using the fixed retrieved knowledge.

Generate exactly:

1. Explanations
2. Key Vocabulary
3. Exercises
4. Self-Assessment Questions

Strict grounding requirements:

Use only the Fixed Retrieved Curriculum Knowledge.  
Advanced difficulty must come from deeper reasoning about the same fixed knowledge, not from adding new scientific knowledge.  
Do not introduce external scientific information or mechanisms.  
Do not include Down Syndrome or meiotic errors/non-disjunction.  
Do not include Mitosis.  
Do not introduce Meiosis I, Meiosis II, named meiotic stages, crossing over, homologous chromosomes, genetic variation, fertilization, DNA mechanisms, or any other information not contained in the fixed knowledge.  
Do not introduce hypothetical chromosome numbers that are not part of the fixed curriculum knowledge. Use only the fixed human example of 46 and 23 chromosomes when quantitative reasoning is required.  
Do not invent causal mechanisms to explain chromosome stability. Use only the fixed curriculum statement that meiosis contributes to maintaining the constancy and stability of chromosome numbers across generations.  
Every analytical or justification question must be fully answerable using only the Fixed Retrieved Curriculum Knowledge.  
Maintain exactly the same scientific core used in the Basic and Intermediate packages.  
Cover all five fixed Learning Objectives.

Important: Make the package Advanced through reasoning, integration, comparison, interpretation, and justification—not through additional biological facts.

Generate only the Advanced package. Do not regenerate Basic or Intermediate content.
