# Basic Level Generation Prompt

## Experiment

Experiment 2 – Meiosis

## Learner Level

Basic

## Original Prompt

Generate the Basic-Level Educational Package for the fixed Meiosis lesson.

Use only the previously fixed:

Curriculum Source  
Meiosis Scope  
Five Learning Objectives  
Fixed Retrieved Curriculum Knowledge  
Four-Component Output Structure

Apply only the Basic Pedagogical Profile:

Use simple and familiar vocabulary while explaining essential scientific terms.  
Focus on essential concepts.  
Use short, clear sentences.  
Provide high scaffolding.  
Keep the concept load limited.  
Use simple and direct examples based only on the fixed curriculum knowledge.  
Target mainly Remember and Understand.  
Assume low learner independence.  
Exercises and self-assessment should focus mainly on recall and simple understanding.

Generate exactly these four sections:

1. Explanations
2. Key Vocabulary
3. Exercises
4. Self-Assessment Questions

Strict grounding requirements:

Use only the Fixed Retrieved Curriculum Knowledge.  
Do not add external scientific information.  
Do not include Down Syndrome or meiotic errors.  
Do not include Mitosis.  
Do not introduce Meiosis I, Meiosis II, named meiotic stages, crossing over, homologous chromosomes, genetic variation, or other mechanisms not contained in the fixed knowledge.  
Do not increase difficulty by adding new scientific knowledge.  
Cover all five fixed Learning Objectives.

Generate only the Basic package. Do not generate Intermediate or Advanced content.
