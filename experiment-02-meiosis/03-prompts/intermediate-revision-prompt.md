## Original Revision Prompt

Revise the Intermediate-Level Meiosis Educational Package while preserving the same Intermediate Pedagogical Profile and the same four-component output structure.

The current version appropriately increases cognitive demand to Understand and Apply, but some items expand beyond the Fixed Retrieved Curriculum Knowledge.

Please make the following corrections:

Keep all explanations, exercises, examples, and answer guides strictly within the Fixed Retrieved Curriculum Knowledge.

Do not explain mechanisms for chromosome stability across generations beyond the fixed statement that meiosis contributes to maintaining the constancy and stability of chromosome numbers across generations.

Remove the unsupported causal explanation that gamete formation “prevents chromosome numbers from multiplying across generations.”

Do not introduce hypothetical chromosome counts such as 14, 48, or 64. Use the fixed curriculum example of 46 chromosomes in the parent reproductive cell and 23 chromosomes in the resulting cells/gametes when numerical application is required.

Replace “developmental sequencing” with terminology consistent with the fixed knowledge, such as quantitative progression of meiosis.

Do not introduce fertilization or any additional mechanism to explain chromosome stability.

Do not add Meiosis I, Meiosis II, named meiotic stages, crossing over, homologous chromosomes, genetic variation, or any external scientific information.

Maintain clear differentiation from the Basic package by using:

- moderate scaffolding,
- relationships between the fixed concepts,
- comparison,
- sequencing of the fixed quantitative progression,
- and simple application using only the 46 → 23 → 4-gamete curriculum example.

Cover all five fixed Learning Objectives and retain exactly:

1. Explanations
2. Key Vocabulary
3. Exercises
4. Self-Assessment Questions

Produce the complete revised Intermediate package only.
