# Intermediate Level Generation Prompt

## Experiment

Experiment 2 – Meiosis

## Learner Level

Intermediate

## Original Prompt

Generate the Intermediate-Level Educational Package for the fixed Meiosis lesson.

Keep exactly the same:

Curriculum Source  
Meiosis Scope  
Five Learning Objectives  
Fixed Retrieved Curriculum Knowledge  
Four-Component Output Structure

Change only the Pedagogical Profile to the fixed Intermediate Profile:

Use curriculum scientific terminology, explaining terms when needed.  
Provide moderate detail and explain relationships between the fixed concepts.  
Use moderately complex sentences and moderate scaffolding.  
Present several related concepts together.  
Use application-oriented examples based only on the fixed curriculum knowledge.  
Target mainly Understand and Apply.  
Assume moderate learner independence.  
Exercises should include relationships, comparison, sequencing, and simple application where these can be created directly from the fixed knowledge.

Generate exactly:

1. Explanations
2. Key Vocabulary
3. Exercises
4. Self-Assessment Questions

Strict grounding requirements:

Use only the Fixed Retrieved Curriculum Knowledge.  
Do not add external scientific information or mechanisms in order to make the content more difficult.  
Do not include Down Syndrome or meiotic errors.  
Do not include Mitosis.  
Do not introduce Meiosis I, Meiosis II, named meiotic stages, crossing over, homologous chromosomes, genetic variation, fertilization, or any other information not contained in the fixed knowledge.  
All application and reasoning questions must be answerable using only the fixed retrieved knowledge.  
Maintain the same scientific core used in the Basic package.  
Cover all five fixed Learning Objectives.

Generate only the Intermediate package. Do not generate Basic or Advanced content.
