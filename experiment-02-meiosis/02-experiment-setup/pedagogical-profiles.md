# Pedagogical Profiles

## Experiment

Experiment 2 – Meiosis

## Purpose

The same three Pedagogical Profiles used in Experiment 1 – Mitosis were retained unchanged for Experiment 2 – Meiosis.

These profiles controlled how the same curriculum-grounded knowledge was presented at different learner levels.

The curriculum source, Meiosis scope, learning objectives, retrieved curriculum knowledge, and output structure were kept fixed. The Pedagogical Profile was the main variable intentionally changed across the three generation conditions.

## Basic Level

| Parameter | Setting |
|---|---|
| Vocabulary | Simple and familiar vocabulary; essential scientific terms explained |
| Explanation Style | Short and clear sentences focused on essential concepts |
| Scaffolding | High |
| Concept Load | Limited |
| Examples | Simple and direct examples |
| Cognitive Demand | Remember and Understand |
| Learner Independence | Low |
| Assessment Focus | Recall and simple understanding |

## Intermediate Level

| Parameter | Setting |
|---|---|
| Vocabulary | Curriculum scientific terminology, with explanation when needed |
| Explanation Style | Moderate detail with relationships between concepts |
| Scaffolding | Moderate |
| Concept Load | Several related concepts presented together |
| Examples | Application-oriented examples |
| Cognitive Demand | Understand and Apply |
| Learner Independence | Moderate |
| Assessment Focus | Sequencing, relationships, comparison, and simple application |

## Advanced Level

| Parameter | Setting |
|---|---|
| Vocabulary | Full curriculum scientific terminology |
| Explanation Style | Deeper conceptual relationships while remaining within the Grade 8 curriculum scope |
| Scaffolding | Low |
| Concept Load | Integrated related concepts |
| Examples | Reasoning-oriented use of the same curriculum knowledge |
| Cognitive Demand | Apply and Analyze |
| Learner Independence | High |
| Assessment Focus | Explanation, prediction, justification, comparison, and conclusion |

## Grounding Constraint

The Advanced profile was intended to increase reasoning depth and cognitive demand without introducing external, higher-grade, or unsupported scientific content.

Advanced therefore meant deeper reasoning using the same curriculum knowledge, rather than adding new scientific knowledge.

All three Pedagogical Profiles were required to remain fixed throughout the Meiosis experiment.
